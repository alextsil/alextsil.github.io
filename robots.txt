# IMPORTANT: why this file is grouped the way it is:
# robots.txt matching is "most specific group wins, and ONLY that group
# applies". A crawler that matches a named User-agent group never reads the
# `User-agent: *` group at all. So a Content-Signal placed only under `*`
# reaches none of the crawlers that are named below it. Every group here
# therefore carries its own Content-Signal line. Multiple User-agent lines
# before one set of rules form a single group, which keeps this readable.
#
# NOTE: Cloudflare's "managed robots.txt" / AI Crawl Control feature will
# PREPEND its own block above this file and can override these rules.
# It must be disabled in the Cloudflare dashboard for this file to apply.
# Cloudflare's Security -> Bots -> "Block AI Scrapers and Crawlers" toggle
# blocks at the edge regardless of this file, and must stay OFF.
